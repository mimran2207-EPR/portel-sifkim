# מרכז הדרכה לספקים — פורטל Muni (EPR)

תאריך: 2026-10-05 · בעלים: יהודה מימרן, מנהל הדיגיטל, EPR

## מטרה

אתר הדרכה אינטראקטיבי בעברית שמלמד ספקים לתפעל את פורטל הספקים של Muni
(`eprvendorst.eprmuni.co.il`). אווטאר של יהודה (דמות תלת-ממד מצוירת) מלווה את הספק
שלב אחר שלב, בהשראת ההדרכה של ועדת הבחירות המרכזית.

## חוויה

- פריסה RTL: תפריט מודולים מימין, צילום מסך של הפורטל במרכז עם סימון (עיגול/חץ) על
  האזור הרלוונטי, אווטאר בעיגול בפינה, כתובית תמיד מוצגת, ניווט הקודם/הבא/השמע שוב.
- התקדמות נשמרת ב-`localStorage`.
- נייד: אווטאר עובר למעלה, תפריט כמגירה.
- עד שקיים קטע וידאו לשלב — מוצגת תמונת האווטאר עם בועת טקסט.
- נתוני הדגמה בלבד בצילומים (ללא שמות, ח.פ, טלפונים וסכומים אמיתיים).

## טכני

- React + Vite + TypeScript + Tailwind, נפרס ל-Cloudflare Worker `portel-sifkim`
  (Static Assets), build אוטומטי מ-`main` במאגר `mimran2207-EPR/portel-sifkim`.
- תוכן ב-`src/content/lessons.ts` (מודולים → שלבים: id, כותרת, תסריט, צילום, מיקום סימון).
- צילומים: `public/screens/<step>.png`; וידאו: `public/avatar/<step>.mp4` (מעבר ל-R2 אם יגדל).
- תסריטים ל-HeyGen: `docs/heygen-scripts.md`.
