# סרטוני אווטאר ב-HeyGen

## התוכנית הנוכחית: סרטון לכל שלב

- סרטון אחד לכל אחד מ-31 השלבים. התסריט הוא שדה `script` של השלב ב-`src/content/lessons.ts`, מילה במילה.
- אווטאר: "יהודה מימראן", דמות תלת־ממד בגוף מלא, רקע שחור, פורמט Portrait.
- שם הקובץ: `<מספר השלב>.mp4` (למשל `3.1.mp4`), נשמר בתיקייה `public/avatar/`.
- שלב שעדיין אין לו סרטון מוקרא באתר בקריינות הקולית (MP3), עם תמונות האווטאר הסטטיות.

### תהליך לכל סרטון

1. מדביקים את התסריט ב-https://app.heygen.com/create-video/new, ממשיכים ב-Continue עד המסך Confirm avatar.
2. לוחצים Generate video, ובסיום Download, ושומרים כ-`public/avatar/<id>.mp4`.
3. מריצים `python scripts/process-video.py <id>`. הסקריפט מעביר את המקור ב-HD ל-`private/videos/` (לא עולה לגיטהב), יוצר MP4 דחוס של 540px ו-WebM עם רקע שקוף.
   אם שלב הסרת הרקע נכשל (קורה לפעמים בגלל נעילת קובץ של OneDrive), מריצים שוב:
   `python scripts/cutout-video.py private/videos/<id>-hd.mp4 public/avatar/<id>.webm`
4. `git add public/avatar/<id>.mp4 public/avatar/<id>.webm`, ואחר כך commit ו-push. Cloudflare מעדכן את האתר אוטומטית.
